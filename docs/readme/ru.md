# FlowHMR-Windows

[简体中文](../../README.md) · [繁體中文](zh-TW.md) · [English](en.md) · [日本語](ja.md) · [한국어](ko.md) · **Русский** · [Français](fr.md)

**FlowHMR-Windows** — приложение для захвата движения из видео на вашем компьютере. Импортируйте видео, выберите одного или нескольких людей и восстановите их движения в 3D для синхронного просмотра и экспорта. Для реконструкции используется модель исходного проекта [FlowHMR](https://github.com/flowhmr/flowhmr). В этом независимом репозитории поддерживаются портативная версия для Windows, управление моделями и средами выполнения, а также рабочий процесс от выбора людей до экспорта.

**[Скачать портативную версию для Windows](https://github.com/xiaoerofficial021-collab/FlowHMR-Windows/releases/latest/download/FlowHMR-Windows.zip)** · [Примечания к выпуску](https://github.com/xiaoerofficial021-collab/FlowHMR-Windows/releases/latest) · [Статья FlowHMR](https://arxiv.org/abs/2610.03691)

## Версия для Windows

- **Захват движения в одном окне.** Выберите людей и диапазон кадров, затем просмотрите исходное видео и 3D-движение рядом. Воспроизведение, перемотка и повтор синхронизированы по шкале времени. Можно включить исходный звук и переключать отображение сетки и скелета.
- **Просмотр и экспорт нескольких людей вместе.** Выберите нескольких людей из одного видео. Общая сцена и FBX сохраняют их относительные позиции и моменты появления в кадре. Предыдущие задачи можно открыть в истории с миниатюрами.
- **Настройка движения под материал.** Регулируйте сглаживание, коррекцию контакта стоп и высоту пола. Включите HaMeR для более точного движения пальцев. По умолчанию используется неподвижная камера. Если камера заметно поворачивается, наклоняется или кренится, выберите режим подвижной камеры.
- **Локальная обработка.** Установите среду инференса и модели по мере необходимости. Модели загружаются при запуске генерации. После установки видео можно обрабатывать без интернета. Интерфейс доступен на 简体中文, 繁體中文, English, 日本語, 한국어, Русский и Français. Приложение запоминает выбранный язык.
- **Экспорт движения.** Доступны FBX для FlowHMR, Mixamo и MetaHuman, MMD VMD и NPZ. В FBX для FlowHMR и Mixamo можно включить сетку и T-позу или A-позу в кадре **−1**. См. [инструкцию по экспорту](../retarget-export.md).
- **Свои персонажи.** Просматривайте PMX и FBX скиненных моделей Mixamo или MetaHuman, назначайте персонажей отдельно каждому участнику и сохраняйте настройки костей. Совместимые PMX поддерживают IK и FK.

## Быстрый старт

1. В 64-разрядной Windows 10 или 11 полностью распакуйте `FlowHMR-Windows.zip`. Откройте папку `FlowHMR` и запустите `FlowHMR.exe`. В базовый пакет входят Python, интерфейс и компонент экспорта FBX.
2. Установите совместимый драйвер видеокарты. В правом верхнем углу откройте **Среда** (运行环境), скачайте и включите подходящую среду. Для NVIDIA выберите CUDA; для RTX серии 50 рекомендуется CUDA 12.8. Для видеокарт AMD Radeon серии RX 9000 на архитектуре `gfx1201` доступна экспериментальная установка ROCm по инструкции ниже.
3. Откройте **Модели** и выберите **Скачать все общедоступные модели** (下载全部公开模型) или загрузите модели по отдельности. Файлы проверяются и помещаются в `models/`. SAM 3D Body и VGGT-Omega загружаются с ModelScope. При загрузке по отдельности можно пропустить HaMeR, если уточнение пальцев не нужно. Официальные модели, для загрузки которых требуется вход, приведены ниже.
4. Перетащите видео в приложение, выберите людей и диапазон кадров, затем запустите генерацию. Результат можно просмотреть и экспортировать в FBX, VMD или NPZ через меню.

### AMD Radeon серии RX 9000 (экспериментальная поддержка)

Для AMD и NVIDIA используются одни и те же `FlowHMR-Windows.zip` и `FlowHMR.exe`. В Windows 11 с видеокартой Radeon серии RX 9000 на архитектуре `gfx1201` при первом запуске откройте **Среда**, скачайте и включите **ROCm 7.14.0 · gfx1201**. Приложение запомнит выбор и автоматически выберет совместимую видеокарту AMD. Модели устанавливаются одинаково.

Скачивание и распаковка официальных пакетов AMD, а также загрузка библиотек проверены. Полный захват движения на RX 9070 XT, включая оценку движения камеры и HaMeR, ещё не проверен на таком оборудовании. См. [инструкцию по установке и проверке AMD](../../docs/amd-rocm.md).

### Какие официальные модели скачать?

Войдите на [официальную страницу загрузок MANO](https://mano.is.tue.mpg.de/download.php). **Для базового захвата движения к общедоступным моделям из предыдущего шага достаточно добавить один из официальных пакетов ниже. Если у вас уже есть `mano_v1_2.zip`, пакет с нейтральной моделью скачивать необязательно.** Если установлены оба пакета, по умолчанию используется нейтральная модель.

| Назначение | Пункт загрузки на официальном сайте | Куда распаковать вручную |
| --- | --- | --- |
| Нейтральная модель тела для базового захвата движения | **Extended SMPL+H model** (AMASS), `smplh.tar.xz` | `models/body_models/smplh/` |
| Мужская и женская модели тела для базового захвата; также включает файлы MANO для уточнения пальцев | **Models & Code**, `mano_v1_2.zip` | `models/` |

После загрузки откройте **Модели → Импортировать архив моделей…** (模型 → 导入模型压缩包…) и выберите файл `mano_v1_2.zip` или `smplh.tar.xz`. Приложение само распакует архив, распознает модели и установит их в нужные папки. Исходный архив сохранится, а в окне моделей будет видно, какие группы готовы и каких файлов не хватает. Если вы уже распаковали архив, выберите **Импортировать распакованную папку…** (导入已解压文件夹…).

Для уточнения пальцев нужны файлы MANO из `mano_v1_2.zip` и общедоступная модель **HaMeR**. Её можно скачать отдельно в строке HaMeR или с помощью кнопки **Скачать все общедоступные модели**.

Полная структура папок для ручной установки, ссылки и назначение моделей описаны в разделе [Файлы моделей](../../models/README.md).
