# FlowHMR-Windows

[简体中文](../../README.md) · [繁體中文](zh-TW.md) · [English](en.md) · [日本語](ja.md) · [한국어](ko.md) · **Русский** · [Français](fr.md)

**FlowHMR-Windows** — приложение для захвата движения из видео на вашем компьютере. Импортируйте видео, выберите одного или нескольких людей и восстановите их движения в 3D для синхронного просмотра и экспорта. Для реконструкции используется модель исходного проекта [FlowHMR](https://github.com/flowhmr/flowhmr). В этом независимом репозитории поддерживаются портативная версия для Windows, управление моделями и средами выполнения, а также рабочий процесс от выбора людей до экспорта.

**[Скачать портативную версию для Windows](https://github.com/xiaoerofficial021-collab/FlowHMR-Windows/releases/latest/download/FlowHMR-Windows.zip)** · [Примечания к выпуску](https://github.com/xiaoerofficial021-collab/FlowHMR-Windows/releases/latest) · [Статья FlowHMR](https://arxiv.org/abs/2610.03691)

## Что нового в v0.3.5

- **Захват движения на CPU.** Процессоры Intel и AMD x64 могут обрабатывать видео с неподвижной и подвижной камерой без GPU. Уточнение движений пальцев с помощью HaMeR в этом режиме недоступно.
- **Новые экспериментальные варианты для GPU.** Добавлены среды для встроенной графики AMD, Radeon RX 5000 и Intel XPU. На совместимых системах AMD со встроенной графикой SAM может распределять работу между CPU и GPU, чтобы снизить расход видеопамяти. В режиме Intel XPU GPU кодирует изображения для SAM, а CPU выполняет остальные этапы.
- **Поиск людей в выбранном диапазоне.** Анализируются только выбранные кадры. При изменении диапазона поиск запускается заново. Для предпросмотра и выравнивания сцены сохраняются номера кадров исходного видео.
- **Импорт локальных персонажей при включённом прокси.** Исправлена ошибка, при которой системный прокси мог перехватывать локальные запросы к файлам PMX, VRM и FBX ([#7](https://github.com/xiaoerofficial021-collab/FlowHMR-Windows/issues/7)).

[Примечания к выпуску](../release-windows.md) · [v0.3.4: исправление выравнивания сцены при нехватке видеопамяти](https://github.com/xiaoerofficial021-collab/FlowHMR-Windows/releases/tag/windows-v0.3.4)

## Системные требования и поддерживаемое оборудование

| Компонент | Требования и рекомендации |
| --- | --- |
| ОС | 64-разрядная Windows 10 или 11. Windows 11 рекомендуется и требуется для AMD ROCm и Intel XPU. |
| ОЗУ | Не менее 16 ГБ. Рекомендуется от 32 ГБ, особенно при обработке на CPU или встроенной графике. Для длинных видео может потребоваться больше. |
| Режим только CPU | Intel / AMD x64. Видеокарта и видеопамять не требуются. Рекомендуется от 32 ГБ ОЗУ. |
| Видеопамять (только для дискретных GPU) | Захват движения проверен при 6 ГБ видеопамяти. Рекомендуется от 8 ГБ. |

| Устройство | Среда выполнения | Статус |
| --- | --- | --- |
| NVIDIA GeForce RTX 50 | CUDA 12.8 | Проверено |
| NVIDIA GeForce RTX 30 / 40 | CUDA 12.1 | Проверено |
| NVIDIA GeForce RTX 20 | CUDA 12.1 | Экспериментально |
| NVIDIA GeForce GTX 10 | CUDA 12.1 | Экспериментально |
| AMD Radeon RX 9000 / 7000 | [ROCm](../amd-rocm.md) | Проверено |
| AMD Radeon RX 5000 | [ROCm](../amd-rocm.md) | Экспериментально |
| Встроенная графика AMD Radeon (включая 740M / 760M / 780M и некоторые модели 800M) | [ROCm](../amd-rocm.md) | Экспериментально (графика 9950X проверена; рекомендуется неподвижная камера) |
| Intel Arc A / B и некоторые встроенные GPU Core Ultra Arc | [Intel XPU](../windows.md) | Экспериментально (GPU только кодирует изображения для SAM) |
| Процессоры Intel / AMD x64 | [Только CPU](../windows.md) | Проверено (AMD Ryzen 9 9950X); Intel — экспериментально |

Уточнение движений пальцев с помощью HaMeR недоступно в режимах CPU и Intel XPU. Встроенная оценка положения кистей в SAM продолжает работать.

## Версия для Windows

- **Захват движения в одном окне.** Выберите людей и диапазон кадров, затем просмотрите исходное видео и 3D-движение рядом. Воспроизведение, перемотка и повтор синхронизированы по шкале времени. Можно включить исходный звук и переключать отображение сетки и скелета.
- **Просмотр и экспорт нескольких людей вместе.** Выберите нескольких людей из одного видео. Общая сцена и FBX сохраняют их относительные позиции и моменты появления в кадре. Предыдущие задачи можно открыть в истории с миниатюрами.
- **Настройка движения под материал.** Регулируйте сглаживание, коррекцию контакта стоп и высоту пола. В совместимой среде для GPU можно включить HaMeR для более точного движения пальцев. По умолчанию используется неподвижная камера. Если камера заметно поворачивается, наклоняется или кренится, выберите режим подвижной камеры.
- **Локальная обработка.** Установите среду инференса и модели по мере необходимости. Модели загружаются при запуске генерации. После установки видео можно обрабатывать без интернета. Интерфейс доступен на 简体中文, 繁體中文, English, 日本語, 한국어, Русский и Français. Приложение запоминает выбранный язык.
- **Экспорт движения.** Доступны FBX для FlowHMR, Mixamo, MetaHuman и Maya AdvancedSkeleton, MMD VMD, VRM Animation (VRMA) и NPZ. В FBX для FlowHMR и Mixamo можно включить сетку и T-позу или A-позу в кадре **−1**. См. [инструкцию по экспорту](../retarget-export.md).
- **Свои персонажи.** Просматривайте PMX, VRM 0.x или 1.0 и FBX скиненных моделей Mixamo или MetaHuman, назначайте персонажей отдельно каждому участнику и сохраняйте настройки костей. Совместимые PMX поддерживают IK и FK.

## Быстрый старт

1. В 64-разрядной Windows 10 или 11 полностью распакуйте `FlowHMR-Windows.zip`. Откройте папку `FlowHMR` и запустите `FlowHMR.exe`. В базовый пакет входят Python, интерфейс и компонент экспорта FBX.
2. Нажмите **«Среда»** в правом верхнем углу, скачайте и включите среду для вашего устройства по таблице выше. При необходимости обновите графический драйвер. Для режима CPU графический драйвер не нужен.
3. Откройте **Модели** и выберите **Скачать все общедоступные модели** (下载全部公开模型) или загрузите модели по отдельности. Файлы проверяются и помещаются в `models/`. SAM 3D Body и VGGT-Omega загружаются с ModelScope. При загрузке по отдельности можно пропустить HaMeR, если уточнение пальцев не нужно. Официальные модели, для загрузки которых требуется вход, приведены ниже.
4. Перетащите видео в приложение, выберите людей и диапазон кадров, затем запустите генерацию. Результат можно просмотреть и экспортировать в FBX, VMD, VRMA или NPZ через меню.

Приложение проверяет обновления в фоновом режиме. Нажмите **Проверить обновления…** рядом с выбором языка, чтобы прочитать примечания к выпуску, установить обновление из скачанного ZIP или выбрать предыдущую версию. Если GitHub недоступен, можно продолжить работу с текущей версией.

### Какие официальные модели скачать?

Войдите на [официальную страницу загрузок MANO](https://mano.is.tue.mpg.de/download.php). **Для базового захвата движения к общедоступным моделям из предыдущего шага достаточно добавить один из официальных пакетов ниже. Если у вас уже есть `mano_v1_2.zip`, пакет с нейтральной моделью скачивать необязательно.** Если установлены оба пакета, по умолчанию используется нейтральная модель.

| Назначение | Пункт загрузки на официальном сайте | Куда распаковать вручную |
| --- | --- | --- |
| Нейтральная модель тела для базового захвата движения | **Extended SMPL+H model** (AMASS), `smplh.tar.xz` | `models/body_models/smplh/` |
| Мужская и женская модели тела для базового захвата; также включает файлы MANO для уточнения пальцев | **Models & Code**, `mano_v1_2.zip` | `models/` |

После загрузки откройте **Модели → Импортировать архив моделей…** (模型 → 导入模型压缩包…) и выберите файл `mano_v1_2.zip` или `smplh.tar.xz`. Приложение само распакует архив, распознает модели и установит их в нужные папки. Исходный архив сохранится, а в окне моделей будет видно, какие группы готовы и каких файлов не хватает. Если вы уже распаковали архив, выберите **Импортировать распакованную папку…** (导入已解压文件夹…).

Для уточнения пальцев нужны файлы MANO из `mano_v1_2.zip` и общедоступная модель **HaMeR**. Её можно скачать отдельно в строке HaMeR или с помощью кнопки **Скачать все общедоступные модели**.

Полная структура папок для ручной установки, ссылки и назначение моделей описаны в разделе [Файлы моделей](../../models/README.md).
