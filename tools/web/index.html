        带蒙皮时使用当前预览体型。仅用于重定向时，导出动画骨架即可。

        参考姿势是 FBX 第 −1 帧的关键帧。Blender 默认导入后在第 0 帧，需切到姿态位置查看。

        选择目标角色的原版 Mixamo FBX。导出会保留模板自带的蒙皮。留空时使用通用 Mixamo 骨架。

        预览角色

        选择 PMX、VRM 或带蒙皮的 Mixamo / MetaHuman FBX。外置贴图请放在 PMX 或 FBX 旁边。

        在桌面版应用新角色时，模型和引用的贴图会存入 models/characters。角色选择和骨骼调节会自动记住。
